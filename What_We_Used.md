# What We Used

### Mapping & Localization
- SLAM(Cartographer)

### Path Planning
- Nav2
- Global Costmap for pathing
- Local Costmap for obstacle avoiding

### Exploration
- Frontier Exploration
- LiDAR used for obstacle avoidance


### - Human Detection
- Lightweight YOLOv8 object detection model
- TF2 transforms to project the bounding boxes into world coordinates to the global frame
